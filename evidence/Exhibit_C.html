Source: GNT written communication concerning the Talos 5X terminal event.

Status: Primary broker explanation — underlying server/deal records remain pending.

1. What GNT explained

GNT described a 90% threshold, sequential liquidation, and a negative balance after liquidation in its explanation of the terminal Talos 5X event.

This is the broker's own account of how the account reached its terminal state.

2. Why this record matters

The explanation is important because the Talos 5X account still showed customer economic value immediately before the terminal event. GNT's description therefore provides evidence about the mechanism it says governed the subsequent liquidation and account outcome.

It also provides a concrete broker explanation that can be compared with the account statements, daily confirmations, transaction records and any server-side records produced later.

3. What this exhibit does not prove

GNT's explanation is not a substitute for the underlying server-side trade, liquidation and account-journal records. By itself, it does not independently establish the complete sequence of transactions, the precise timing of each liquidation, or every component of the final account calculation.

The broker's explanation should therefore be read as an important primary statement about the event, while the transaction-level reconciliation remains open.

4. The question still to be reconciled

The remaining task is to reconcile GNT's written explanation against the underlying broker-side records showing the account's trades, liquidation sequence, balances, credits, debits and terminal entries.

If those records materially change the factual reconstruction, the public account should be corrected accordingly.
